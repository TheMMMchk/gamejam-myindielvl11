## Integration guidance

- Keep the existing Player GameObject, Rigidbody2D, CircleCollider2D and movement scripts unchanged. Assign the selected flame sprite to the existing SpriteRenderer only after checking scale and pivot in Unity.
- Import pixel art with **Texture Type: Sprite (2D and UI)**, **Filter Mode: Point (no filter)**, **Compression: None**. Keep Pixels Per Unit consistent across the selected pack; do not mix arbitrary PPU values.
- For sprite sheets, set **Sprite Mode: Multiple**, open Sprite Editor, slice by the documented cell size, and create an animation only when the corresponding gameplay state is ready.
- Avoid adding a separate light source or changing the URP 2D Global Light as part of this asset import. The gameplay/level-design branches own scene assembly.
- Do not mix all sources automatically: inspect them in Unity first. The flame, fuel prop and bonfire should read as one visual family against the dark environment. Prefer a small coherent subset over a large collection of mismatched sprites.
